    东华掠影

    这是什么项目？

    这是一个由受"新生事项"、《大学生活质量指北》、《上交生存手册》启发的常见资料汇总项目，意在帮助新生们大概了解东华大学(DHU)，同时了解社团、学生组织等方面的信息。

    查询 & 贡献 & 提问

    您可以直接在本站查询问卷收集到的DHU相关资料。贡献、提问、部分资料查询请前往 Discussions。

    询问更多DHU相关信息请加入 东华大学2026.7官方新生QQ群集锦。

    1. 对于没有 Git 使用背景的同学们：请在 Discussions Ideas 提出你的想法！咱会帮助你上架。
    2. 对于熟悉 Git 操作的同学：请对 docs 路径下的对应文件夹 Pull Request，Merge 后便即时上线。文件名请全部使用英文，不允许有空格，请使用 - 代替空格。
    3. 如需更新内容，请及时联系咱 ο(=•ω＜=)ρ⌒☆！
