# 电脑选购指南

大学期间，电脑几乎是每个同学的刚需。面对五花八门的品牌、型号和参数，很多新生都会感到困惑。这篇指南帮助你根据自己的专业和需求做出合理选择。

## 先搞清楚：我需要什么？

!!! question "先问自己三个问题"

    1. **我的专业对电脑有什么要求？**（见下方分类）
    2. **我除了学习还会用电脑做什么？**（打游戏、剪视频、编程等）
    3. **我的预算是多少？**

## 按专业分类

### 文科/经管类（管理学院、人文学院、外语学院等）

日常主要用 Office 办公套件、网页浏览、看视频、轻度数据处理。

| 推荐 | 说明 |
|------|------|
| 轻薄本 | 够用且便携，续航好 |
| 预算 | 4000-6000 元即可满足需求 |
| 不建议 | 不需要独立显卡，不需要游戏本 |

### 理工科（纺织、机械、信息、计算机、材料、化工、环境等）

可能需要运行专业软件（MATLAB、CAD、仿真工具等），计算机类专业需要编程。

| 推荐 | 说明 |
|------|------|
| 全能本/轻薄游戏本 | 有一定性能，比纯游戏本轻便 |
| 预算 | 5000-8000 元 |
| 注意 | 计算机专业建议内存 16G 以上 |
| 不建议 | 太重的游戏本（每天背着累） |

### 设计/艺术类（服装设计、环境设计、数字媒体等）

需要运行 Adobe 全家桶（PS、AI、PR 等）、3D 建模软件。

| 推荐 | 说明 |
|------|------|
| 高性能本/移动工作站 | 需要好的屏幕色域和独立显卡 |
| 预算 | 7000-12000 元 |
| MacBook | 设计专业常见选择，但确认软件兼容性 |
| 注意 | 屏幕色域比性能更重要（选 100% sRGB） |

## 笔记本 vs 台式机 vs 平板

| 类型 | 优点 | 缺点 | 适合谁 |
|------|------|------|--------|
| **笔记本** | 便携、带到教室/图书馆 | 同价位性能弱于台式 | **绝大多数同学首选** |
| **台式机** | 性能强、散热好、可升级 | 不能移动 | 重度游戏/渲染需求、宿舍空间允许 |
| **平板** | 看课件、记笔记方便 | 不能完全替代电脑 | 作为笔记本的**补充**，不建议作为唯一设备 |

!!! tip "关于 MacBook"
    MacBook 续航好、屏幕好、适合设计和编程。但注意：

    - 需要注意使用习惯（macOS 与 Windows 操作逻辑不同）
    - 提前确认自己专业需要的软件是否支持 macOS

## 什么时候买？在哪买？

- **时间**：开学前（暑假）或开学后都可以，不着急的话可以入学后看看同学买了什么再决定
- **渠道**：京东自营、天猫官方旗舰店、品牌官网（保修方便）
- **不建议**：电脑城、非授权小店（容易被忽悠加价换配置）
- **Apple 教育优惠**：凭录取通知书或学生证可享折扣 + 赠品（通常在暑假期间），官网或线下 Apple Store 均可

## 常见疑问

**Q: 一定要买新电脑吗？家里的旧电脑能用吗？**
A: 如果旧电脑能满足需求，完全可以继续用，不用急着换。

**Q: 可以先不买电脑吗？**
A: **一定要电脑！** 小组作业、文档编辑、学工系统（PC 端体验远好于移动端）等都需要电脑。学校有机房和图书馆公共电脑，但有自己的电脑会方便非常多。

**Q: 游戏本有必要吗？**
A: 如果你不玩大型游戏、不需要跑 3D 软件，轻薄本就够了。游戏本重、续航短，每天来回背不太方便。
