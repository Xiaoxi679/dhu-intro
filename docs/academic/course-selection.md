# 选课与绩点

## 选课流程

!!! warning "选课系统"
    选课期间教务平台可能非常卡（甚至进不去），请耐心等待。**时刻关注教务处网站的通知！**

### 选课阶段

| 阶段 | 时间 | 说明 |
|------|------|------|
| **第一轮选课** | 军训期间 | 与选课时间无关。课程人数未满则直接录取，超过最大人数则系统**随机录取**，有概率被退课。趋冷避热降低落选概率 |
| **第二轮选课** | 开学前 | **拼手速！** 对第一轮没选上的课再选。没抢到可以多刷新查看是否有多出名额（可能有同学退课） |
| **补退选** | 开学后两周内 | 可删除不想上的课程 |

### 选课前准备

1. 打开 [网上服务大厅](https://ehall.dhu.edu.cn) → 登录 → 进入**教务系统**
2. 在个人主页找到【公共查询】→【专业教学计划】，查看本专业必修课和选修课要求
3. 【选课学期开设课程】提前查看课程开设情况
4. 制定课表，避免时间冲突

### 选课操作

进入教务系统 → 点击【选课】开始选课。

- **作息时间**：上午 8:15-11:35 / 下午 13:00-17:05 / 晚上 18:00-21:20
- **课程代码**："x教xxx"→延安路校区；"松xxx"→松江校区
- **学分要求**：平均每学期约 15 学分以上
- **分层教学**：英语根据分级考成绩分班，具体见选课手册与教务处通知

!!! tip "选课建议"
    - 选课可以去学校机房或用自己的电脑，这两处网速较快
    - **提前 10-15 分钟**进入选课页面等待，防卡顿
    - 第一轮选课**趋冷避热**降低落选风险
    - 第二轮没抢到可多刷新看是否有退课名额
    - 临近毕业没选上必修课，可联系教务处（021-67792206）询问扩容事宜

### 选课平台

- 第二轮拼手速可以提前10-15分钟进入选课页面

## 学分要求

专业培养方案由四部分组成：

| 课程类别 | 说明 |
|----------|------|
| 通识教育课程 | 政治法律、自然科学、军事体育、人文素养、创新创业等 |
| 学科基础课程 | 数学、物理、计算机、外语等，按不同规格开设 |
| 专业教育课程 | 专业必修课 + 专业选修课 |
| 实践教育课程 | 实验、实习、毕业设计等 |

!!! info "选课要求"
    - 必修课必须修读取得全部学分
    - 选修课需取得各类别规定的学分数
    - 对学科基础课程中的选修课，主要选修本专业的学科基础选修课
    - 一学期取得的学分数（辅修课程除外）少于 15 学分者，给予**学业警告**

> 具体请参考各专业培养方案，可在教务系统中查看。

## 绩点（GPA）

东华大学采用 **5.0 绩点制**（来源：《东华大学本科生学生手册》）。

### 绩点计算公式

课程考核成绩以百分制（X）记入成绩册，对应绩点数（K）：

| 考核成绩 X（百分制） | 绩点数 K |
|:---:|:---:|
| 60 ~ 100 | **K = 0.1X − 5** |
| < 60（不及格） | 0 |

即：60 分对应 1.0，70 分对应 2.0，80 分对应 3.0，90 分对应 4.0，100 分对应 5.0。

### 平均学分绩点（P）

$$P = \frac{\sum (Y_i \times K_i)}{\sum Y_i}$$

其中 $Y_i$ 为课程学分，$K_i$ 为该课程绩点。即：**学分加权平均**。

!!! info "不计入绩点的课程"
    军事训练和理论、综合实践类课程、劳动教育、形势与政策、创新创业教育、体育课、文化素质类选修课、心理健康教育课、辅修专业学士学位课程**不计入**学分绩点；奖励学分计入。

!!! warning "评优绩点"
    智育测评、推荐免试研究生等评奖评优的学分绩点以**第一次考核（含缓考）**成绩计算，补考和重新修读成绩**不计入**评优学分绩点。授予学位的学分绩点以每门课程最高分（含补考和重新修读）计算。

### 绩点用途

- 学位授予（专业平均学分绩点须 ≥ 1.7）
- 智育测评、评奖评优（一等奖学金评优绩点 ≥ 2.5 等）
- 推荐免试研究生（保研）
- 出国留学申请
- 转专业参考

## 体育课

体育课是通识教育课程的一部分（军事体育类），属于必修课。体育类课程按不同规格开设，可根据自己的水平和兴趣选择。

!!! info "体育相关须知"
    - 体育课**不计入绩点**，但需修满规定学分
    - **体测成绩不低于 50 分**方可满足毕业要求（依据《学生手册》）
    - 部分奖学金/评优要求**体育成绩 70 分以上**
    - 因身体原因不能参加体育课/体测的，可凭证明申请保健课或免测（具体流程咨询校医院和辅导员）

## 常见问题

### 大学考试有哪些类型？

| 类型 | 说明 |
|------|------|
| **平时作业** | 成绩占比高达 30%-50%（签到、习题、小组作业等），认真完成还能避免期末突击 |
| **随堂小测** | 课前5分钟或章节结束后的测试，督促边学边消化 |
| **课程论文/报告** | 需查文献、列框架、注意引用格式 |
| **期末闭卷/开卷考** | 闭卷考侧重知识体系串联，开卷考考验快速定位和灵活运用 |
| **体育考试** | 体能测试（800/1000米等）+ 专项技能，必修 |
| **英语四六级** | 大学生"标配"考试，听力占比高，早准备多刷题 |

> 常用考试工具（iTEST、企业微信、学习通等）请在[学习资源](resources.md)页面中查看。

### Q: 选课系统太卡进不去怎么办？
A: 耐心多试几次，避开高峰时段。课是肯定会有的，不用太焦虑。

### Q: 可以跨专业选课吗？
A: 学生可申请辅修校内其他专业或选修其他专业课程；学校推行主辅修制和跨本科专业大类修读辅修专业制度，学有余力者可报名（主修专业绩点需 ≥ 1.7）。周六、周日主要安排辅修专业课程。

### Q: 挂科后可以补考/重修吗？
A: 课程考核不及格，可在下学期开学前参加补考（成绩注明"补考"）。补考仍不及格：**必修课**必须重新修读，**选修课**可重修该门或选修培养方案内的其他课程。注意：
- 无故缺考 / 考试违纪作弊：成绩记 0 分，**不予补考**，只准重新修读
- 重新修读成绩注明"重修"
- 评优绩点只算第一次考核（含缓考）成绩，补考和重修不计入评优
