# 学生组织

## 班级委员会（班委）

班委是班级日常运转的核心，一般通过竞选产生。常见班委及职责：

| 职位 | 核心职责 |
|------|----------|
| **班长** | 统筹全班工作，是辅导员、老师与同学沟通的桥梁；组织策划班会、班级活动；传达通知；协调其他班委 |
| **团支书** | 负责团支部思想建设、组织建设；组织主题团日活动、青年大学习；管理团员档案、收缴团费；配合做好"推优入党"工作 |
| **易班班长** | 班级网络平台发言人，管理易班班级群 |
| **学习委员** | 与老师对接收交作业，反馈同学学习问题 |
| **生活委员** | 管理班费，关心同学生活需求 |
| **文体委员** | 组织班级文体活动、运动会报名 |
| **心理委员** | 关注同学心理状态，协助联系心理咨询中心 |

!!! tip "关于竞选"
    - 大一入学后一般会组织班委竞选，准备好一段自我介绍
    - 竞选班长/团支书竞争相对激烈，但也最锻炼能力
    - 如果不想做太忙的职务，生活委员、心理委员是不错的选择
    - 班委会工作经验对评奖评优有一定帮助

## 招新时间

学生组织招新通常在每学年开学初（9 月）进行：
- **开学前**：部分组织会通过新生群宣传
- **开学第一周**：集中宣讲/百团大战
- **开学第二周**：面试、录取

具体时间请关注各组织公众号和新生群通知。
